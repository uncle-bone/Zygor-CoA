# Zygor-CoA v1.0.10 — Research Integration

**Status:** Experimental integration package; in-game validation pending. The repository README describes the package but does not assert that v1.0.10 has been uploaded as a GitHub release asset.

## Changes
- Integrated the available Pale Reach research into one native Zygor guide rather than separate single-quest guide entries.
- Packaged 237 Pale Reach quest records, 134 recorded prerequisite relationships and 41 coordinate records (reported coverage: 32 quests).
- Preserved the native Zygor guide browser, quest tracker, waypoint system, Gear Finder and CoA Talent Advisor.
- Scope for **new guide development**: Vanilla Azeroth and Conquest Reborn custom content; no new TBC/Wrath guide work.

## Known limitations
- Research records are not all verified as currently live on Conquest Reborn.
- Complete quest objectives, turn-in steps, waypoints and routing are not yet verified.
- The full-zone guide and partial-character progress behavior have not passed in-game tests.
- Pale Reach is level 18–60 **only with level scaling enabled**.

## Installation
Back up `ZygorGuidesViewerRM` and SavedVariables, then extract the single addon folder into `Interface/AddOns`. Do not rename it.
